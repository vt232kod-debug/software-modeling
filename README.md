Усі чотири роботи побудовані навколо **однієї наскрізної предметної області** — сервісу **«Півот»** для вивчення іноземної мови на власному контенті користувача: браузерне розширення з подвійними субтитрами поверх відеоплеєрів та вебзастосунок зі словником, інтервальними повтореннями й читалкою документів.

## Інструмент

Моделі описані кодом у **PlantUML** (підхід «діаграма як код»), що дозволяє версіонувати їх у Git. Кожна діаграма зберігається трьома файлами:

- `*.puml` — вихідний код моделі;
- `*.svg` — векторний рендер;
- `*.png` — растровий рендер для вставки у звіт.

Перерендерити будь-яку діаграму:

```bash
plantuml -tsvg діаграма.puml && plantuml -tpng діаграма.puml
```

У ЛР1 для порівняння CASE-інструментів та сама тестова діаграма додатково побудована у **Mermaid** (`.mmd`) і **Draw.io** (`.drawio`).
